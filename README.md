# Dhker

ذِكر — تطبيق Flutter عربي لمواقيت الصلاة والقرآن، مع أساس محلي للأذكار والتنبيهات.

## الحالة

المستودع في مرحلة التطوير. يتضمن التطبيق الحالي واجهة أولية لمواقيت الصلاة والقرآن، وقاعدة SQLite محلية منفصلة للمحتوى وبيانات المستخدم. قاعدة المحتوى تبدأ بتصنيفات الأذكار فقط؛ لم تُضف نصوص أو تسجيلات قبل توثيق مصادرها وتراخيصها.

## تشغيل قاعدة البيانات

يُنشئ التطبيق القاعدتين عند التشغيل الأول. لا يحتاج إنشاء المخطط إلى خدمة خلفية أو حساب مستخدم. راجع [توثيق قاعدة البيانات](docs/database.md) و[سياسة المحتوى](docs/content-policy.md).

لتثبيت الاعتماديات وتشغيل الاختبارات من بيئة Flutter:

```bash
flutter pub get
flutter test
```

## الخصوصية والمصادر

تُحفظ بيانات قاعدة المستخدم محليًا في مساحة التطبيق الخاصة. لا تتضمن هذه الطبقة رفع بيانات أو تحليلات. راجع تراخيص أي بيانات أو ملفات قبل إعادة توزيعها؛ راجع `docs/content-policy.md`.
