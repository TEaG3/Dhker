# مكتبة أصوات الأذان

تُجلب التسجيلات العشرة التالية من مستودع [Kiwifu/adhan-mp3](https://github.com/Kiwifu/adhan-mp3) أثناء بناء التطبيق، ثم تُضمّن داخل APK لتعمل دون اتصال بالإنترنت.

| المؤذن | التسجيل المعتمد |
|---|---|
| محمد رمضان سعد | الحرم المكي |
| علي بن أحمد ملا | الحرم المكي |
| محمد خليل رمل | الحرم المكي |
| نايف فداح | الحرم المكي |
| فاروق عبدالرحمن حضراوي | الحرم المكي |
| عاصم بخراري | الحرم المكي |
| نور الدين حمزة المغربي | المسجد الأقصى |
| ناجي قزاز | المسجد الأقصى |
| مشاري راشد العفاسي | الكويت |
| عبد الباسط عبد الصمد | مصر |

تُستخدم التسجيلات من المصدر المشار إليه بناءً على وصف المستودع الذي يذكر إتاحتها للتطبيقات الإسلامية وبرامج مواقيت الصلاة والاستخدام الشخصي. يُحفظ اسم المؤذن ومكان التسجيل كما وردا في المصدر، ولا ننسب أي تسجيل إلى شخص آخر.

تُحمّل الملفات تلقائياً في GitHub Actions إلى `assets/adhan/` وتُنسخ إلى موارد Android الخام لتعمل أصوات التنبيهات دون إنترنت. لا تُخزّن الملفات الثنائية في Git؛ بل تُجلب عند البناء لضمان بقاء المستودع خفيفاً.

المصدر: https://github.com/Kiwifu/adhan-mp3
