# Third-party notices — Quran Library evaluation

This branch evaluates `quran_library` 5.0.1. The package's Dart code is
licensed under MIT; retain the upstream copyright and license notice.

**Important resource distinction:** the package's upstream NOTICE states that
QCF Quran fonts and tafsir/translation files or other resources obtained from
Quranic Universal Library (QUL) or King Fahd Glorious Quran Printing Complex
(KFGQPC) are not covered by the package's MIT code license. Their respective
terms apply when bundling or distributing them.

The upstream NOTICE also summarizes a QUL condition against distracting ads
inside apps/projects while users read the Quran. Before production release,
review the current official QUL and KFGQPC terms directly and confirm which
assets are bundled versus downloaded on demand.

Sources:
- https://github.com/alheekmahlib/quran_library/blob/main/LICENSE
- https://github.com/alheekmahlib/quran_library/blob/main/NOTICE
- https://qul.tarteel.ai/
- https://qurancomplex.gov.sa/quran-dev/

This evaluation branch does not authorize production distribution of Quran
fonts or third-party tafsir/translation resources.
