# Third-party notices — Quran Library evaluation

This branch evaluates `quran_library` 5.0.1. The package's Dart code is
licensed under MIT; retain the upstream copyright and license notice.

**Important resource distinction:** QCF Quran fonts and tafsir/translation
files or other resources obtained from Quranic Universal Library (QUL) or King
Fahd Glorious Quran Printing Complex (KFGQPC) are not covered by the package's
MIT code license. Their respective terms apply when bundling or distributing
those assets.

The upstream NOTICE also summarizes a QUL condition against distracting ads
inside apps/projects while users read the Quran. Before a production release,
review the current official QUL and KFGQPC terms and confirm which assets are
bundled versus downloaded on demand.
