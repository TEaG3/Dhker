# قاعدة البيانات المحلية

ينشئ التطبيق قاعدتي SQLite في مجلد قاعدة البيانات الخاص بالتطبيق على الجهاز:

- `dhker_content.db`: تصنيفات الأذكار، نصوص الأذكار، مصادرها وتخريجها، الأحاديث، وبيانات تسجيلات الأذان وتراخيصها.
- `dhker_user.db`: الإعدادات، المواقع المحفوظة، مواقيت الصلاة المحسوبة مؤقتًا، تقدم الأذكار، التسبيح، موضع القراءة، المفضّلات، تفضيلات الأذان والتنبيهات، وبيانات الملفات المنزلة.

لا يتطلب هذا التصميم خادمًا أو اتصالًا بالإنترنت للقراءة من المحتوى الموجود محليًا. لا تُرسل بيانات المستخدم إلى أي خدمة عبر طبقة قاعدة البيانات.

## التنفيذ الحالي

المنفّذ حاليًا هو أساس SQLite باستخدام `sqflite`، مع إصدار مخطط أولي (`version 1`) واختبارات SQLite عبر FFI. تُنشأ فئات المحتوى الثماني عند أول تشغيل، لكن لا تُضاف نصوص أذكار أو أحاديث أو ملفات أذان تلقائيًا. هذا مقصود إلى حين مراجعة النصوص وتوثيق مصادرها وتراخيصها. تبقى المدن في `assets/data/cities.json` كما هي في هذه المرحلة.

قاعدة المحتوى منفصلة منطقيًا عن بيانات المستخدم، لكن `dhker_content.db` يُنشأ محليًا حاليًا لتأسيس المخطط. لم يُنفّذ بعد تضمين قاعدة محتوى جاهزة للقراءة فقط أو توقيعها أو نظام تحديثها.

## الجداول

### `dhker_content.db`

- `content_categories`: تصنيفات الأذكار وترتيبها.
- `content_sources`: بيانات المصدر والترخيص والإسناد وحالة المراجعة.
- `adhkar`: النص العربي، النص المهيأ للبحث، عدد التكرار، الفضل وحالة التفعيل.
- `adhkar_sources`: ربط الذكر بمصدره والاقتباس المحدد.
- `hadiths` و`adhkar_hadiths`: بيانات الحديث ودرجته ومراجعه وربطه بالأذكار.
- `adhan_recordings`: بيانات التسجيل والملف ومدة الصوت وحالة التحقق من الترخيص.
- `content_metadata`: بيانات إصدار المخطط وحالة المحتوى.

### `dhker_user.db`

- `app_settings` و`saved_locations` و`prayer_times_cache`.
- `adhkar_progress` و`tasbih_sessions` و`tasbih_daily_totals`.
- `quran_bookmarks` و`quran_reading_position`.
- `adhan_preferences` و`notification_schedules` و`downloaded_media`.

التواريخ المخزنة باسم `local_date` يجب أن تكون بصيغة `YYYY-MM-DD` في المنطقة الزمنية للموقع. الطوابع الزمنية ذات اللاحقة `_utc` تُخزن بصيغة ISO-8601 بالتوقيت العالمي.

## فتح قاعدة البيانات واستخدامها

```dart
final database = await DhkerDatabase.open();
final categories = await database.getCategories();
await database.setSetting('city_id', 'baghdad');
```

يجب إغلاق القاعدتين عند انتهاء دورة حياة مالكهما باستخدام `await database.close()`. يمكن تمرير `directory` إلى `open` في الاختبارات لعزل ملفات SQLite.

## الترحيلات

إصدارات المخطط معرفة في `DhkerDatabase`. عند تغيير الجداول في إصدار لاحق، تُضاف ترحيلات مرتبة داخل `onUpgrade` مع اختبار ترقية قاعدة قديمة؛ لا تُحذف بيانات المستخدم أو تُعاد تهيئتها بصمت. يجب تحديث هذا المستند والاختبارات مع كل تغيير للمخطط.
